# TaskFlow API — CLAUDE.md

## Project Overview

REST API for task management built with Fastify 5 + TypeScript. Handles user auth (JWT + Redis blacklist) and CRUD tasks per user.

## Stack

| Layer        | Technology                          |
|--------------|-------------------------------------|
| Framework    | Fastify 5 (`fastify`)               |
| Language     | TypeScript 6 (ESM, `"type": "module"`) |
| ORM          | Prisma 7 (`@prisma/client`)         |
| Database     | PostgreSQL (`pg`, `@prisma/adapter-pg`) |
| Cache        | Redis (`@fastify/redis`)            |
| Auth         | JWT (`@fastify/jwt`)                |
| Validation   | Zod + `fastify-type-provider-zod`   |
| API Docs     | Swagger/OpenAPI (`@fastify/swagger`, `@fastify/swagger-ui`) |
| Scheduler    | `node-cron`                         |
| Dev runner   | `tsx watch`                         |

## Project Structure

```
src/
  server.ts                  # Entry point — Fastify instance, plugins, routes
  lib/
    prisma.ts                # Prisma client singleton
    cron.ts                  # Scheduled jobs (overdue task alerts)
  modules/
    auth/
      auth.routes.ts         # POST /api/auth/register, /login, /logout
      auth.schemas.ts        # Zod schemas for auth endpoints
    tasks/
      tasks.routes.ts        # GET/POST/PUT/DELETE /api/tasks
      tasks.schemas.ts       # Zod schemas for task endpoints
  types/
    fastify.d.ts             # Augments FastifyInstance with `authenticate`
  generated/
    prisma/                  # Prisma-generated client
    zod/index.ts             # Zod schemas generated by zod-prisma-types
prisma/
  schema.prisma              # DB schema (User, Task, TaskStatus enum)
scripts/
  cleanup-invalid-emails.ts  # One-off data-cleanup script
docs/
  HYBRID_ZOD_APPROACH.md
```

## Running Locally

Requires `.env` with at minimum:
```
DATABASE_URL=postgresql://...
JWT_SECRET=...
REDIS_URL=redis://localhost:6379
```

Docker Compose is available (`docker-compose.yml`) for Postgres + Redis.

## Key Conventions

- **Validation**: Always use Zod schemas defined in `*.schemas.ts`. Never validate manually inside route handlers.
- **Type provider**: Use `fastify.withTypeProvider<ZodTypeProvider>()` per-plugin so `request.body` is fully typed.
- **Auth guard**: Protected routes use `preHandler: [fastify.authenticate]` or `app.addHook('preHandler', fastify.authenticate)`.
- **Prisma access**: Always import from `../../lib/prisma.js` (note `.js` extension required for ESM).
- **Imports**: All local imports must use `.js` extension (ESM requirement).
- **No test framework yet** — `npm test` exits 1.

## Data Models

### User
```
id        String   (uuid, PK)
email     String   (unique, validated email)
password  String   (bcrypt, min 6 chars)
createdAt DateTime
tasks     Task[]
```

### Task
```
id          String      (uuid, PK)
title       String      (min 1 char)
description String?
status      TaskStatus  (pending | in_progress | completed)
dueDate     DateTime?
userId      String      (FK → User, cascade delete)
createdAt   DateTime
updatedAt   DateTime
```

## API Endpoints

| Method | Path                  | Auth | Description              |
|--------|-----------------------|------|--------------------------|
| POST   | /api/auth/register    | No   | Create user account      |
| POST   | /api/auth/login       | No   | Get JWT token            |
| POST   | /api/auth/logout      | Yes  | Blacklist token in Redis |
| GET    | /api/tasks            | Yes  | List current user tasks  |
| POST   | /api/tasks            | Yes  | Create task              |
| PUT    | /api/tasks/:id        | Yes  | Update task fields       |
| DELETE | /api/tasks/:id        | Yes  | Delete task              |
| GET    | /ping                 | No   | Health check             |
| GET    | /docs                 | No   | Swagger UI               |

## Scheduler

`initScheduler()` in `src/lib/cron.ts` runs every minute and logs `console.warn` for any `pending` task whose `dueDate` is in the past.

## Adding a New Module

1. Create `src/modules/<name>/<name>.schemas.ts` with Zod schemas.
2. Create `src/modules/<name>/<name>.routes.ts` with `FastifyPluginAsync`.
3. Register in `src/server.ts`: `server.register(myRoutes, { prefix: '/api/<name>' })`.
